# AWS cost baseline for FileTasks

Research checked 12 October 2026. Price examples below use **US East (N. Virginia), `us-east-1`, USD**, with public on-demand rates. This is a reproducible price comparison, not a region recommendation: UK or EU deployment prices can differ, so check the target region before choosing one.

## Recommended AWS shape

For 1–5 people and 1–10 GB of documents, an AWS-native backend can have **no always-on compute or database floor**:

```text
Next.js web client ─┐
iOS client ─────────┼─ Cognito sign-in → HTTPS HTTP API → Node.js/TypeScript Lambda
Android client ────┘                                      ├─ DynamoDB for tasks, events, file metadata
                                                          └─ S3 private bucket for File bytes

All clients upload/download File bytes directly to S3 using short-lived presigned URLs.
Future reminders/async work: EventBridge Scheduler → SQS → Lambda, when needed.
```

The API owns authorization and metadata changes; Lambda returns a short-lived S3 `PUT` or `GET` URL for the authorized object. S3 presigned URLs give temporary access to a specific operation without making the bucket public or giving the client AWS credentials. A URL works as an ordinary HTTP endpoint in a browser or mobile app. The web app, Swift app, and Android app can use the same Cognito user pool and API; native clients can send the same HTTPS bearer token and use platform HTTP libraries for the signed file URL. [S3 presigned URL guide](https://docs.aws.amazon.com/AmazonS3/latest/userguide/using-presigned-url.html), [API Gateway HTTP API JWT authorizers](https://docs.aws.amazon.com/apigateway/latest/developerguide/http-api-jwt-authorizer.html), [Amplify Swift frontend libraries](https://docs.amplify.aws/swift/frontend/), [Amplify Android frontend libraries](https://docs.amplify.aws/android/frontend/).

Keeping file bodies out of API Gateway and Lambda matters: API Gateway's own example prices a 4.5 MB document sent through an HTTP API as 9 requests because payloads are metered in 512 KB chunks. Direct S3 upload/download avoids that API metering for each file chunk and avoids Lambda time/memory being used to relay bytes. The app still makes a small authenticated API call to request a signed URL. [API Gateway HTTP API pricing example](https://aws.amazon.com/api-gateway/pricing/).

For metadata, **DynamoDB on-demand** avoids provisioning capacity and charges for request units used. It is a good fit if access patterns can be expressed as keyed lookups and queries; it is less convenient than SQL for ad hoc joins. The current always-free DynamoDB storage offer covers the first 25 GB, but the 25 read/write capacity unit offer is for *provisioned* capacity; the example below therefore prices on-demand reads and writes. [DynamoDB pricing](https://aws.amazon.com/dynamodb/pricing/).

If SQL is more important than keeping every component inside AWS, a PostgreSQL service such as Neon can sit behind the same Lambda/API contract as a separately priced vendor. RDS PostgreSQL is also possible, but it is not required for this low-volume baseline. Keep Lambda outside a customer VPC unless a private network resource requires one: a VPC-attached Lambda that needs internet access generally needs a NAT gateway or suitable endpoints, and NAT is billed hourly and by data processed. [Lambda internet access and VPC guide](https://docs.aws.amazon.com/lambda/latest/dg/configuration-vpc-internet.html), [VPC pricing](https://aws.amazon.com/vpc/pricing/).

### AWS implementation choices

Plain TypeScript CDK is the clearest fit if the backend should remain an independent HTTP contract for web and native clients. It gives direct control over API Gateway, Lambda, S3, DynamoDB, Cognito, and future queues/schedules. Amplify Gen 2 is also TypeScript-first and built on CDK: its `defineAuth`/`defineData`/`defineStorage` conventions speed up a standard app backend, and CDK constructs can be added or overridden. Amplify Data's default generated API is AppSync GraphQL plus DynamoDB, which is a different client/API shape from the HTTP API baseline here. Choose Amplify if those conventions are useful; use custom resources/CDK for the independent API and non-default storage flow. [Amplify Gen 2 custom resources](https://docs.amplify.aws/react/build-a-backend/add-aws-services/custom-resources/), [Amplify Gen 2 overrides](https://docs.amplify.aws/react/build-a-backend/add-aws-services/overriding-resources/), [Amplify Data setup](https://docs.amplify.aws/react/build-a-backend/data/set-up-data/).

## Illustrative monthly cost

Assumptions: one S3 Standard bucket in `us-east-1`; either 5 GB or 10 GB stored all month; 5 GB of monthly internet downloads; 100 S3 PUTs and 10,000 S3 GETs; 10,000 small HTTP API requests; one 256 MB Lambda invocation averaging 100 ms per API request; 10,000 DynamoDB request units read and 10,000 request units written (assuming small items); 1–5 monthly active direct/social Cognito users; and CloudWatch Logs use below the applicable 5 GB free limit. The upload/download count and function duration are examples, not measured FileTasks traffic.

| Component | Public rate and calculation | 5 GB stored | 10 GB stored |
| --- | --- | ---: | ---: |
| S3 Standard storage | $0.023 per GB-month for first 50 TB in `us-east-1` | $0.115 | $0.230 |
| S3 requests | 100 PUT × $0.005/1,000 + 10,000 GET × $0.0004/1,000 | $0.0045 | $0.0045 |
| Internet download egress | 5 GB is below the first 100 GB/month AWS-wide free allowance, assuming other AWS services have not used it | $0 | $0 |
| HTTP API Gateway | 10,000 × $1/million HTTP API requests | $0.010 | $0.010 |
| Lambda, before Always Free | 10,000 × 100 ms × 0.25 GB × $0.0000166667/GB-second, plus $0.20/million requests | $0.0062 | $0.0062 |
| DynamoDB on-demand | 10,000 read units × $0.125/million + 10,000 write units × $0.625/million | $0.0075 | $0.0075 |
| Cognito user pool | 1–5 direct/social MAUs are within the current 10,000 MAU Always Free allowance | $0 | $0 |
| CloudWatch Logs | Assumed below the current 5 GB Always Free monthly allowance | $0 | $0 |
| **Estimated recurring total after applicable Always Free quotas** | Lambda line is covered by its Always Free request and duration quotas; S3 storage and the listed API/DynamoDB on-demand requests remain billable | **about $0.137/month** | **about $0.252/month** |

The storage-only numbers are **$0.115/month for 5 GB** and **$0.23/month for 10 GB**; S3 storage is the largest line at this volume. S3 has no minimum charge. If the Lambda Always Free allowance is unavailable or already used by other functions in the account, this sample adds about $0.0062, for totals of **$0.143/month at 5 GB** and **$0.258/month at 10 GB**; the other free-tier assumptions in the table remain unchanged. This is a small-request estimate: HTTP API request metering rounds payloads in 512 KB chunks, so file bodies must stay on the direct S3 path. [S3 pricing](https://aws.amazon.com/s3/pricing/), [S3 `us-east-1` price list](https://pricing.us-east-1.amazonaws.com/offers/v1.0/aws/AmazonS3/current/us-east-1/index.json), [API Gateway HTTP API pricing example](https://aws.amazon.com/api-gateway/pricing/).

The estimate treats a small API request as one HTTP API call. It does not send the file through that API. AWS charges API Gateway at $1 per million HTTP API requests through the first 300 million in this Region. Lambda's first million requests and 400,000 GB-seconds per month are ongoing Always Free allowances, so the sample Lambda usage is under both. DynamoDB on-demand read/write request units are billed in the sample; its 25 RCU/WCU Always Free offer applies to provisioned capacity, while the first 25 GB of Standard-table storage is included in the Free Tier. Larger items, transactional writes, or strongly consistent reads can consume more request units than this example. [API Gateway pricing](https://aws.amazon.com/api-gateway/pricing/), [Lambda pricing](https://aws.amazon.com/lambda/pricing/), [DynamoDB pricing](https://aws.amazon.com/dynamodb/pricing/).

The current Cognito pool default is Essentials, and Essentials and Lite both have an ongoing 10,000 direct/social MAU free tier per account or AWS Organization. Plus has no MAU free tier. Email and SMS verification/MFA messages have separate SES/SNS pricing, so they are excluded. [Cognito pricing](https://aws.amazon.com/cognito/pricing/).

AWS includes the first 100 GB/month of internet data transfer out across AWS services and Regions, except China and GovCloud; inbound internet transfer to S3 is also free. This is an aggregate allowance, not a separate 100 GB for each service. Keep file downloads direct from S3 so they use that allowance instead of routing bytes through a paid third-party proxy. If other workloads consume the allowance, use the regional transfer price in the AWS calculator for the marginal amount. [AWS global data transfer FAQ](https://aws.amazon.com/about-aws/global-infrastructure/global-network/faqs/), [S3 data transfer pricing](https://aws.amazon.com/s3/pricing/), [AWS Data Transfer Always Free usage list](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/tracking-free-tier-usage.html).

CloudFront has separate free CDN allowances: AWS currently lists 1 TB/month of data transfer and 10 million requests for its pay-as-you-go CloudFront free tier; its newer flat-rate Free plan separately lists 100 GB/month, 1 million requests, and S3 Standard storage credits. These aren't included in the table: it assumes direct S3 presigned downloads, not a CloudFront distribution, and the plan/account eligibility rules differ. At this FileTasks volume, direct S3 downloads already fit within the AWS-wide 100 GB allowance, so CloudFront is not needed to keep the estimate low. If private-file delivery later moves behind CloudFront, price that distribution and confirm its access and account-plan behavior separately. [CloudFront FAQ](https://aws.amazon.com/cloudfront/faqs/), [CloudFront pricing](https://aws.amazon.com/cloudfront/pricing/), [CloudFront flat-rate plan guide](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/flat-rate-pricing-plan.html).

### Free usage versus launch credits

At the research date, AWS advertises a $100 sign-up credit plus up to $100 more for eligible activity, for up to $200 over six months. A Free account plan is for exploration, includes selected services and Always Free usage, and closes when six months end or credits run out unless upgraded. A Paid account plan remains open and can access both Always Free offers and short-term trials; it is billed beyond remaining credits. Credits can make initial invoices smaller, but they are not the steady-state cost baseline. [AWS Free Tier](https://aws.amazon.com/free/), [AWS Free Tier plans](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/free-tier-plans.html), [AWS Free Tier usage](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/free-tier.html).

Relevant ongoing offers for the proposed stack are Lambda (1 million requests and 400,000 GB-seconds/month), DynamoDB (25 GB storage and 25 provisioned RCU/WCU/month), Cognito (10,000 MAUs for Essentials/Lite direct or social sign-in), CloudWatch Logs (5 GB/month across ingestion, archive storage, and Logs Insights scans), SQS (1 million requests/month), EventBridge Scheduler (14 million invocations/month), and AWS internet data transfer out (first 100 GB/month, aggregated across services/Regions with stated exclusions). The EventBridge and SQS allowances are comfortably above a personal reminder workload; reminder email/SMS delivery still has separate delivery-service charges. [Lambda pricing](https://aws.amazon.com/lambda/pricing/), [DynamoDB pricing](https://aws.amazon.com/dynamodb/pricing/), [Cognito pricing](https://aws.amazon.com/cognito/pricing/), [CloudWatch pricing](https://aws.amazon.com/cloudwatch/pricing/), [SQS pricing](https://aws.amazon.com/sqs/pricing/), [EventBridge Scheduler pricing](https://aws.amazon.com/eventbridge/pricing/), [S3 pricing](https://aws.amazon.com/s3/pricing/).

AWS's S3 FAQ currently displays a one-year offer of 5 GB S3 Standard storage, 20,000 GETs, and 2,000 PUTs per month for new customers. The API Gateway pricing page displays 1 million HTTP API calls per month for up to 12 months. If the account is eligible for those temporary offers, they cover the sample's S3 requests and API calls; the S3 storage offer covers 5 GB, reducing the temporary storage charge to zero in the 5 GB case and to about $0.115/month in the 10 GB case. However, AWS's new-account material also describes the post-July-2025 credit plans, and its Free Tier documentation says only Paid plans get short-term trials while Free plans get Always Free offers. The public pages do not make the applicability to every credit-era account fully clear, so these trial savings are excluded from the table and must be verified in that account's Billing/Free Tier view. The S3 internet transfer offer also overlaps the separate ongoing 100 GB data-transfer allowance; the estimate assumes the ongoing aggregate allowance is available. [S3 FAQ and offer text](https://aws.amazon.com/s3/faqs/), [API Gateway pricing and offer text](https://aws.amazon.com/api-gateway/pricing/), [AWS Free Tier account plans](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/free-tier-plans.html), [AWS Free Tier offer types](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/free-tier.html).

## Storage portability and a hybrid option

If file egress becomes the dominant cost after the aggregate 100 GB/month AWS allowance, the object store can be changed independently while keeping Cognito, Lambda, the HTTP API, and metadata database in AWS. Keep the `File` record keyed by an opaque object key and let the backend create provider-specific signed URLs; do not persist a provider URL as the record's identity. A Cloudflare R2 hybrid can use the S3-compatible SDK/signing flow and direct browser/mobile HTTP transfer. R2's current prices list no egress charge, but its presigned URLs use the R2 S3 API hostname and **cannot use an R2 custom domain**. So private signed downloads can use the generated endpoint, while a branded `files.example.com` hostname would need a different access design. This is a later egress optimization, not needed to keep the AWS baseline near a few cents for 1–10 GB. [R2 pricing](https://developers.cloudflare.com/r2/pricing/), [R2 presigned URL limits](https://developers.cloudflare.com/r2/api/s3/presigned-urls/), [R2 S3 API compatibility](https://developers.cloudflare.com/r2/api/s3/api/).

## Small cost controls and deployment notes

Use a single AWS Budget email alert for actual/forecast spend, and set finite CloudWatch log retention so a noisy function cannot accumulate logs indefinitely. CloudWatch's free allowance is 5 GB/month; usage beyond free limits is billed. Budgets are listed among AWS's Always Free services. [CloudWatch pricing](https://aws.amazon.com/cloudwatch/pricing/), [AWS tracked Always Free offers](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/tracking-free-tier-usage.html).

CDK deployment needs a one-time bootstrap per account/Region. The default bootstrap stack includes an S3 asset bucket, IAM roles, and an ECR repository; uploaded deployment assets can incur small ordinary storage charges. Creating an optional customer-managed KMS key for the bootstrap bucket adds a separate billed resource, so it is not part of this baseline. [CDK bootstrapping](https://docs.aws.amazon.com/cdk/v2/guide/bootstrapping.html), [CDK bootstrap CLI reference](https://docs.aws.amazon.com/cdk/v2/guide/ref-cli-cmd-bootstrap.html).
