# FileTasks

FileTasks helps people manage personal tasks and events alongside the files they need for them. This glossary defines the product concepts used across its calendar, reminders, and file library.

## Planning and reminders

**Task**:
An item that represents an action a person needs to complete.
_Avoid_: To-do, event

**Event**:
A dated or timed item a person wants to remember, whether or not it requires an action.
_Avoid_: Task, appointment (unless it is specifically an appointment)

**Occurrence**:
One dated instance of a recurring task or event. Each task occurrence has its own completion state.
_Avoid_: Repeat, recurrence (when referring to one instance)

**Recurrence rule**:
A pattern that determines when occurrences of a task or event are scheduled and when the pattern ends.
_Avoid_: Repeat setting

**Reminder**:
A timed alert associated with a task or event, delivered through an in-app notification or email.
_Avoid_: Alarm (unless referring to a device alarm)

**Reminder default**:
An account-level set of reminders applied to newly created tasks or events of the corresponding type. Task and event defaults are configured separately.
_Avoid_: Global reminder (when distinguishing task and event defaults)

## Files

**File**:
An uploaded document or external file link that a person keeps in the Files section and can associate with tasks and events.
_Avoid_: Attachment (when referring to the file itself)

**Attachment**:
An association between a file and a task, event, recurrence series, or individual occurrence.
_Avoid_: File (when referring to the association)

**Files section**:
The central collection of a person's uploaded files and external file links, including the tasks and events associated with each one.
_Avoid_: File manager

## Calendars

**Connected calendar**:
A Google or Apple calendar linked to FileTasks so its events can be viewed and kept in sync with FileTasks.
_Avoid_: Imported calendar

**Calendar copy**:
An event representation in a connected calendar that corresponds to an event in FileTasks.
_Avoid_: Source event (unless the event originated in the external calendar)
